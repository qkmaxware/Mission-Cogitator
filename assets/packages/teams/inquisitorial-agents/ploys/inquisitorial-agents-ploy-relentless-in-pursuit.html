--- { "kind": "firefight", "name": "Relentless In Pursuit", "art-path": null, "art-caption": null } --- Use this firefight ploy when an enemy operative within 2" of a ready friendly INQUISITORIAL AGENT operative performs an Action in which it moves. After it moves, that friendly INQUISITORIAL AGENT operative can either perform a free Reposition Action, but must end that move within 2" of that enemy operative, or a free Charge action, but must end that move within control range of that enemy operative. If neither is possible, that friendly operative cannot perform those actions, this ploy isn't used and the CP spent on it is refunded.
