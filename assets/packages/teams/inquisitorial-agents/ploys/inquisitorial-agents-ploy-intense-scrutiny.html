--- { "kind": "strategy", "name": "Intense Scrutiny", "art-path": null, "art-caption": null } --- Whenever you’re selecting a valid target for a friendly INQUISITORIAL AGENT operative, enemy operatives within 4" of it cannot be in Cover (instead of 2"). While this can allow such operatives to be targeted (assuming they’re Visible), it doesn’t remove their cover save (if any), unless the friendly INQUISITORIAL AGENT operative is within 2" as normal.
