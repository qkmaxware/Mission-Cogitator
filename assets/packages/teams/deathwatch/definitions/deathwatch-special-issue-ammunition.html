--- { "name": "Special Issue Ammunition" } --- Once per turning point, when a friendly DEATHWATCH operative is performing the Shoot action, in the Select Weapon step, you can use this rule. If you do, select one of the following weapon rules for that operative's ranged weapons to have until the end of the action. This rule cannot be used with explosive grenades (see universal equipment) or melta bombs.
  • Blast 1" (you cannot select this if the weapon profile being used has the Torrent weapon rule)
  • Devastating 1
  • Lethal 5+
  • Piercing Crits 1
  • Saturate
  • Severe
