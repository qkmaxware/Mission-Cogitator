--- { "name": "Transfer Power", "ap": 1 } --- This rule is a part of the Noospheric Network faction rule.
  • During a friendly Battleclade Servitor's activation, once per activation, you can spend 1 AP to Transfer Power allowing that friendly operative to act using NETWORK COUNTERACT at the end of this operative's activation.
  • The operative using Transfer Power must have APL 2 or higher; if it has been reduced below 2 APL (for example by Stun or another effect), it cannot use Transfer Power.
