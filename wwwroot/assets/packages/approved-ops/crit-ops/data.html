--- { "name": "Data", "kind": "primary", "archetype": "fixed", } --- Victory Points:

At the end of the second and third turning point, if friendly operatives have performed more Compile Data actions during that turning point than the enemy operatives, you score 1VP

Whenever a friendly operatives performs the Send Data action you score VP equal to the number of Data points removed.

Mission Action:
Compile Data (1AP)

  • One objective marker the active operative controls gains 1 Data point.
  • An operative cannot perform this action during the first turning point, while within control range of an enemy operative, or if that objective marker has already gained a Data point during this turning point.

Send Data (1AP)

  • Remove all Data points from an objective marker during the active operative controls.
  • An operative cannot perform this action during the first, second, or third turning points, while within control range of an enemy operative, or if that objective marker has doesn't have any Data points to remove.
